# Finam Chart — сборка виджета

Статическая сборка расширения `com.mminakov.finam-chart` для FinamX Open Platform (`renderMode: external-embed`).
Файлы: `index.html`, `app.js`, `style.css`. Исходники и сборка (esbuild) лежат в локальном проекте open-platform, здесь только результат `npm run build`.
